# TMRW Phone beta.4 — อัปเดตอัตโนมัติ

เปิด `auto_update: true` ให้ Extension และเพิ่มตัวตรวจอัปเดตเมื่อเปิดด้วย
`tmrw-start` แยกรุ่น Extension กับแพ็กเสียง ไม่โหลดโมเดลใหม่ถ้ารุ่นเสียงเดิม
รุ่นนี้ยังใช้ Local Voice **1.0.0-beta.1** ประมาณ 780 MB จาก release beta.3
ไม่มีการสร้างเสียงใหม่ เปลี่ยนชื่อพรีเซ็ท หรือแก้ API key ของผู้เล่น

## ผู้เล่นใหม่

สำหรับ Android arm64 ที่มี ST ใน Termux อยู่แล้ว เตรียมพื้นที่ว่าง 4 GiB:

```bash
curl -fL --proto '=https' https://github.com/luftmenschiv-arch/SillyTavern-Extension-TMRW-Phone/releases/download/v0.1.0-beta.4/install.sh -o "$TMPDIR/tmrw-install.sh" && bash "$TMPDIR/tmrw-install.sh"
```

จากนั้นเปิดด้วย `tmrw-start` ตามปกติ ถ้า ST อยู่นอก `~/SillyTavern` เติม
`--st=/พาธจริง/SillyTavern` ท้ายคำสั่ง bash

## ผู้ที่ลง public beta.3 แล้ว

ทำครั้งเดียว: รอจบการโทร/สร้างคำตอบ สำรองข้อมูล อัปเดต Extension จาก ST ให้เป็น
beta.4 ปิด ST แล้วใช้ `tmrw-start --stop-voice` จากนั้นรันคำสั่ง beta.4 ด้านบน
อีกครั้ง ระบบใช้แพ็กเสียงเดิม ไม่โหลดโมเดลใหม่ เสร็จแล้วเปิดด้วย `tmrw-start`

คำแนะนำนี้ไม่ใช่การย้ายชุด private/ทดลองเก่า ห้ามลบแชทหรือ IndexedDB เพื่อข้าม
คำเตือน หากมีไฟล์โค้ดแก้เอง/พาธพิเศษ ตัวติดตั้งอาจหยุดให้ตรวจแยก

## พฤติกรรมอัปเดต

- ตรวจ snapshot บน public main ก่อน fast-forward ไม่ force/reset ทับโค้ดผู้เล่น
- ตรวจไฟล์/เครื่องมือ/health ของแพ็กเสียงใหม่ก่อนเปิดใช้ เก็บแพ็กเดิมและกู้กลับ
  หากเปิดไม่ผ่านหรือการสลับรุ่นค้าง โดยไม่ทับโปรไฟล์เสียงผู้เล่นและประวัติ
- ถ้า ST หรือบริการเสียงยังเปิด จะเลื่อนอัปเดต ไม่ตัดสายกลางทาง
- เน็ตหลุดใช้รุ่นเดิมต่อ รันซ้ำใช้ส่วนดาวน์โหลดที่ตรวจแล้ว
- ตัวอัปเดตเองเก็บ code engine แยกเวอร์ชัน ไม่สลับไฟล์ครึ่งชุด
- `tmrw-start --updates-off` / `--updates-on` ปิด/เปิดการตรวจตอนเริ่ม;
  `--update-only` ตรวจโดยไม่เปิด ST ระบบอัปเดตภายใน ST เป็นอีกส่วนหนึ่ง

78/78 focused tests ผ่าน รวม KeyFlow 1.5.1 และการเก็บข้อมูล บน Android อัปเดต
จาก beta.3 ไปสาขาเตรียมปล่อยสำเร็จ ระบบเสียงเปิดได้และข้อมูลเสียง 27 ไฟล์กับ
ประวัติทดสอบยังอยู่ครบ ทดลอง candidate จำลองที่เปิดไม่ผ่านและ transaction ค้าง
แล้วกู้กลับสำเร็จ การทดสอบ Android
ใช้โฟลเดอร์แยก ไม่ใช่เครื่องใหม่ที่เพิ่งลง Termux การตรวจ snapshot ไม่รับประกัน
ว่า Extension ไม่มีบั๊กทุกกรณี ไม่ได้เพิ่มการย้อนโค้ดหลังโหลด UI โดยอัตโนมัติ
503 ของผู้ให้บริการและคุณภาพการออกเสียงบางพรีเซ็ทยังเป็นข้อจำกัดของ beta

ไม่ต้องดาวน์โหลด `runtime.part-*` ซ้ำด้วยมือ ตัวติดตั้งอ่าน URLs และ hashes
ของแพ็กเดิมจาก index ที่ตรึงไว้ ไฟล์ beta.3 เดิมไม่ถูกแก้หรือแทนที่
